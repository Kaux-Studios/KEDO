KEDO 1.0.0 — primera versión estable. Desde acá rige la garantía de [ADR-0001](https://github.com/Kaux-Studios/KEDO/blob/main/spec/adr/0001-versionado-semver.md): 1.x sólo agrega (nada que compilaba deja de hacerlo ni cambia de significado) y un cambio que rompe es 2.0. Vale para el lenguaje, el AST, el IR, los frames, los códigos de diagnóstico, la CLI y la API pública de `Kedo.Core` y `Kedo.Compiler`.

- **Igual que 1.0.0-alpha.5** en el lenguaje, el compilador, la VM y la CLI. Se corta ahora porque Project Patriark ya escribió con KEDO su contenido completo: eventos, misiones con etapas, árboles de conversación, accesos, plazos y comportamientos. Nada de eso pidió cambios al núcleo.
- **Addon de Godot:** `kedo/prepare_command`. Si un proyecto lo fija y la CLI no devuelve JSON, la pantalla muestra «KEDO is not prepared» y un botón **Prepare KEDO** que corre el comando y recarga el catálogo.
- **Para 1.x** (aditivo): permitir palabras reservadas (`not`, `set`, `on`…) como nombres de campo de un record; hoy no se pueden usar.
- **Consumo:** los juegos siguen usando KEDO por código fuente fijado a un commit o tag (enmienda de ADR-0002). Los paquetes se publican en GitHub Packages para quien los quiera.

99 pruebas, más las pruebas headless del addon.
